# Krishna Kanwar — Portfolio

A personal portfolio for Krishna Kanwar, a computer science undergraduate specializing in Artificial Intelligence and Machine Learning. It introduces Krishna's interests, skills, and projects, with interactive features built using HTML, CSS, and JavaScript.

## Features

- Profile, skills, and project sections
- Light and dark theme toggle
- Weather lookup by city
- AI assistant section for questions about the portfolio and its projects

The weather lookup requires an internet connection. The AI assistant is intended for local classroom demonstrations and may not be available on the deployed site.
